# QA Atlas 0.7.4 — исправление входа для старой PostgreSQL-базы

- В `backend/src/database.mjs` добавлена обратносуместимая автоматическая
  миграция `sessions`, `login_attempts`, `account_tokens`: `expires_at INTEGER`
  → `BIGINT`. В PostgreSQL 32-битный INTEGER не вмещает Unix-время в
  миллисекундах; старые БД сохраняли ошибочный тип, поскольку файлы миграций
  уже числились применёнными.
- Операция выполняется транзакционно, только для столбцов старого типа;
  без удаления таблиц, аккаунтов, сессий, проектов или иных данных.
- Добавлены регрессионные тесты `tests/postgres-expirations.test.mjs`.
- Проверены синтаксис Node.js, 3 теста миграции, 3 теста валидации авторизации.
- Полноценное испытание на PostgreSQL/Docker не выполнялось: сервер и Docker
  отсутствуют в среде, npm-зависимости для ряда старых тестов не установлены.

## Обновление

Сохраните `.env` и резервную копию БД. Распакуйте новую версию, перенесите
`.env` и запустите `docker compose up -d --build`. При старте backend исправит
существующие столбцы PostgreSQL. `docker compose down -v` **не выполнять**.

Экстренная SQL-команда для установки старой версии — в README.
