# QA Atlas 0.8.3 — очистка и проверка

## Изменения
- Дополнительное сравнение прогонов и кандидаты на нестабильность свёрнуты по умолчанию. В заголовках видны счётчики; отчёты и экспорт доступны после раскрытия.
- Запросы командного интерфейса теперь ограничены 15 секундами для чтения и 150 секундами для остальных операций. По истечении ожидания запрос прерывается, интерфейс получает понятную ошибку. Автоматического повторения записей нет: истечение ожидания не доказывает отмену операции на сервере.
- HTTP-статус сохраняется даже при ответе сервера не в JSON; поддержан пустой ответ 204.
- Опрос проектов, фоновых заданий, автопрогонов и семантического индекса не запускает следующий запрос до завершения предыдущего.
- Запоздавший ответ обновления дефектов не перезаписывает более свежий список; ответы после ухода со страницы игнорируются.
- Экспорт дефектов использует общий помощник скачивания, удалён дублирующий код.
- Исправлено зависание тестового стенда PDF при раннем завершении FastAPI. Добавлены проверки HTTP-клиента и гонки списка дефектов.

## Запуск

Настройте `.env` по `.env.example`, затем:

```bash
docker-compose up --build
```

Подробные шаги и API — в README. При обновлении сохраните существующий `.env`, пользовательские файлы и Docker volumes. Не используйте `down -v`. Архив частично проверен, не является подтверждением готовности production-окружения.
