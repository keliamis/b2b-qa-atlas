# Проверка QA Atlas 0.7.9 — 31 октября 2026

Статус поставки: **PARTIALLY VERIFIED**. Архив не называется submission_ready: критический Docker/PostgreSQL прогон не выполнен. Основа — фактически приложенный `QA_Atlas_0.7.7_requirements_hierarchy_fix(1).zip` (package.json 0.7.7). Отдельная версия 0.7.8 не предоставлена.

## Изменения

- Генерация распределяет квоты между требованиями. Проверяет основную связь, ограничивает перекос, адресно запрашивает пропущенные требования. Всего не более двух обращений к модели, включая исправление JSON. Корректная часть сохраняется при неудачном повторе; сценарии не выдумываются.
- Backend независимо вычисляет missingRequirementIds, partial и список пропущенных требований. UI показывает «Частичный результат» и пояснения в фоновой задаче.
- Redis возобновляет обработку после ready/reconnect. Исполняется ID, полученный из Redis, вместо произвольной первой строки БД. Ошибки enqueue перехвачены; PostgreSQL остаётся источником восстановления очереди.
- Production не запускается без DATABASE_URL, исключён молчаливый fallback на SQLite. Compose ожидает здоровый runner. Сохранены именованные volumes и существующие миграции, включая BIGINT и исправление счётчиков входа.
- Обновлены версии, README, архитектура, .env.example. Добавлены регрессии распределения, реального HTTP-импорта PDF и runner с сохранённым демонстрационным дефектом.
- Два устаревших тестовых контракта приведены к текущему поведению: парсер возвращает requirements; набор произвольных чисел без контекста не считается входными границами. Первоначальное падение последнего теста сохранено в журнале, исправленная проверка пройдена.

## Что осталось перед сдачей

1. В доступной Docker-среде выполнить `docker-compose build --no-cache` и `docker-compose up -d`. Проверить все healthcheck, регистрацию/вход, PDF, генерацию, запуск и экспорт.
2. Настроить действующий AI-ключ/модель. Сверить содержание шести сценариев и их основные связи, проверить реальную генерацию для REQ-051.
3. Перезапустить Compose без удаления volumes и проверить аккаунты, проекты, задачи и историю. Отключить/включить Redis, убедиться в восстановлении queued-заданий.
4. Требование о семантических эмбеддингах остаётся незакрытым. Подключение embeddings API потребует подтверждённой модели, размерности и переиндексации. Старые хеш-векторы не объявляются семантическими.

Прочие ограничения: один backend-инстанс, синхронный SQL-адаптер, отсутствие OCR, отсутствие browser-JS coverage и запуска JUnit. Этот релиз не заявляет полного соответствия всем требованиям презентации.
