# Скидки интернет-магазина
Поле amount — обязательное число, сумма заказа в рублях с точностью 2 знака.
Минимум amount: 0.00. Отрицательные суммы и нечисловые значения должны отклоняться.
При 1000.00 <= amount < 5000.00 скидка 5%.
При amount >= 5000.00 скидка 10%.
Иначе скидки нет. Итог округляется до 2 знаков после запятой.
Для amount = 5000.00 ожидаемый итог 4500.00.
